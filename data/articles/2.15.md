Длина массива не всегда бывает известна. Однако может потребоваться получить ее. Для этого можно использовать несколько способов. Первый способ, который пришел из языка С, 
представляет применение оператора sizeof:

По сути длина массива равна совокупной длине его элементов. Все элементы представляют один и тот же тип и занимают один и тот же размер в памяти. 
Поэтому с помощью выражения sizeof(numbers) находим длину всего массива в байтах, а с помощью выражения sizeof(numbers[0]) - 
длину одного элемента в байтах. Разделив два значения, можно получить количество элементов в массиве.

```cpp
#include <iostream>
 
int main()
{
    const int max {6};     // максимальная длина массива - не больше 6 чисел
    int numbers[max];       // массив для ввода чисел
 
    int i{};        // счетчик введенных чисел
    std::cout << "Enter numbers" << std::endl;
    while(i < max)
    {
        std::cin >> numbers[i];    // вводим число
        i++;
    }
    // выводим массив
    for (i =0; i < max; ++i)
    {
        std::cout << numbers[i] << "\t";
    }
    std::cout << std::endl;
}
```
