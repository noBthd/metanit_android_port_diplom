## Блоки кода

Простой однострочный пример:

```cpp
int age;
```

Многострочный пример с отступами:

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello World!";
    return 0;
}
```

Ещё один блок кода:

```cpp
for (int i = 0; i < 10; i++) {
    std::cout << i << std::endl;
    if (i == 5) {
        std::cout << "Половина пройдена!" << std::endl;
    }
}
```

## Инлайн-код

Можно указать конкретный стандарт, добавив `c++11`, `c++14`, `c++17` или `c++20`. Например, для компиляции в стандарт `c++17` нужно написать:

```cpp
g++ -std=c++17 source.cpp
```
