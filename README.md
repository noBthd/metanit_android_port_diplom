# Metanit C++ Port — iOS-приложение

Мобильное приложение для изучения языка C++ на основе материалов сайта metanit.com.  
Разработано с использованием **Qt 6 / QML** (C++) для iOS и **Go**-сервисов для сбора данных.

## Архитектура

```
diplom/
├── src/                    # Qt/QML приложение (C++)
│   ├── app/main.cpp        # Точка входа
│   ├── core/
│   │   ├── models/         # Структуры данных
│   │   └── services/       # Бизнес-логика
│   └── ui/qml/             # Интерфейс (QML)
├── tools/                  # Go-сервисы
│   ├── crawler/            # Краулер: собирает список статей с metanit.com
│   └── link_to_md/         # Парсер: скачивает статьи и конвертирует в Markdown
├── data/
│   ├── articles.json       # Индекс статей (150 штук, 17 глав)
│   └── articles/           # Markdown-файлы статей
└── CMakeLists.txt
```

## Компоненты

### Qt/QML приложение (C++)

- **ArticleService** — загрузка индекса статей из JSON
- **ArticleModel** — модель данных для QML (главы, статьи, поиск)
- **ArticleFilterModel** — фильтрация статей по поисковому запросу
- **MarkdownService** — загрузка и рендеринг Markdown → HTML

### Go-сервисы

- **crawler** — обходит metanit.com/cpp/tutorial/, собирает ссылки и названия статей, сохраняет в `articles.json`
- **link_to_md** — по каждой ссылке из `articles.json` скачивает страницу, извлекает контент и сохраняет как Markdown

## Сборка и запуск

### Требования
- Qt 6.5+ с модулями: Core, Gui, Widgets, Qml, Quick
- CMake 3.16+
- Go 1.21+ (для сервисов)

### Сборка приложения
```bash
./build.sh
./build/metanit_port
```

### Запуск Go-сервисов
```bash
# 1. Собрать список статей
cd tools/crawler/cmd && go run main.go

# 2. Скачать контент статей
cd tools/link_to_md/cmd && go run main.go
```

## Возможности приложения

- 📖 Просмотр 150 статей по C++, сгруппированных в 17 глав
- 🔍 Поиск по названиям статей в реальном времени
- 📱 iOS-стиль интерфейса (тёмная тема, tab bar, навигация)
